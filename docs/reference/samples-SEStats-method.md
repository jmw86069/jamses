# Get samples from SEStats

Extract sample names from the SEStats object's sedesign.

## Usage

``` r
## S7 method for class <SEStats>
samples(object)
```

## Arguments

- x:

  An `SEStats` object

## Value

Character vector of sample names

## Details

This is a read-only accessor that retrieves the sample names from the
SEDesign object stored in the SEStats object.
