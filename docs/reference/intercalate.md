# Intercalate two or more vectors

Purpose is to take a list of vectors, and intercalate their values

## Usage

``` r
intercalate(...)
```

## Arguments

- ...:

  one or more `character` vectors

## Value

`character` vector with values of each list in `...` combined in
alternating fashion.
