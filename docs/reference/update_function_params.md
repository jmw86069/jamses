# Update function default parameters

Update function default parameters

## Usage

``` r
update_function_params(
  function_name = NULL,
  param_name = NULL,
  new_values = NULL,
  verbose = FALSE,
  ...
)
```

## Details

This function is a minor extension to
[`update_list_elements()`](update_list_elements.md) intended to help
update function parameters which are defined as a nested list.
