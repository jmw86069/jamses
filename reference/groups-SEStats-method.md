# Get groups from SEStats

Extract group names from the SEStats object's sedesign.

## Usage

``` r
## S7 method for class <SEStats>
groups(object)
```

## Arguments

- x:

  An `SEStats` object

## Value

Character vector of group names

## Details

This is a read-only accessor that retrieves the group names from the
SEDesign object stored in the SEStats object.
