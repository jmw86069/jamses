# Contrast matrix accessor for SEDesign objects

Contrast matrix accessor for SEDesign objects

## Usage

``` r
contrasts(x, contrasts = TRUE, sparse = FALSE)
```

## Arguments

- x:

  `SEDesign` object

- contrasts, sparse:

  arguments retained for compatibility with the base
  [`stats::contrasts()`](https://rdrr.io/r/stats/contrasts.html) generic
  signature; ignored for `SEDesign`.
